# 몽라운지 독립형 프로토타입

- 기존 작업 중인 사이트와 완전히 별개인 새 프로젝트입니다.
- 참고 사이트의 정보구조와 주요 기능 흐름(메뉴, 검색, 카테고리, 추천, 지역, 커뮤니티, 이벤트, 내정보 등)을 바탕으로 새 코드/문구/스타일로 작성했습니다.
- 참고 사이트의 원본 소스코드, 로고, 이미지, 업체 데이터, 고유 문구는 복제하지 않았습니다.

## 실행
압축을 풀고 PowerShell:

cd E:\mong-lounge-site
python -m http.server 5600

브라우저:
http://localhost:5600/
